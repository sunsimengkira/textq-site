Common topics

Start here.

01

Paste a list.

Copy spreadsheet rows, use TextQ’s Paste control, and review the import summary before continuing.

02

Import CSV or Excel.

Choose a .csv or .xlsx file when paste is not convenient. Lists can include headers, and TextQ reports skipped rows.

03

Personalize with your columns.

Use placeholders that match imported column titles, such as {firstName}, {address}, or {date}.

04

Preview and Review.

Check the first personalized Preview while writing, then review recipients before starting either sending option.

05

Send One by One.

Review each prepared text in Apple Messages and tap Send yourself. Cancelling pauses the queue without marking that recipient sent.

06

Set up or recover Fast Send.

Add the named TextQ Fast Send Shortcut once, start it only from TextQ, keep Shortcuts open until TextQ returns, and use the in-app recovery steps if a run is interrupted.

07

Free usage and TextQ Pro.

Understand the first 30 cumulative Processed recipients, plan options, Restore Purchases, and current sending limits.

08

Messages and replies.

Messages use your own number through Apple Messages, and replies stay there. TextQ does not provide carrier delivery confirmation.

Contact Support

Still stuck?

Try the step again and note the exact message TextQ shows. If you contact Support, include your iPhone model, iOS version, TextQ version, what you tapped, and the exact error text.

Please do not email a real contact list or screenshots that show private recipient information.
